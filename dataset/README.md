
# Dataset

This folder contains the mathematical symbol
images used for training and testing the CNN model.

## Classes
- Addition (+)
- Subtraction (-)
- Multiplication (x)
- Division (/)
- Equal (=)

## Image Specification
- Image Size: 32 x 32 pixels
- Color Format: Grayscale
- Pixel Depth: 8-bit

The dataset will be generated using Python.
